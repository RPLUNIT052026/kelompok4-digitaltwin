# Digital Twin Room  — Multi-Room Closed-Loop Smart Lab

Sistem pemantauan dan kendali kenyamanan ruangan berbasis **Digital Twin** (Flask + SQLite WAL) dengan ilustrasi gradasi arsitektural adaptif per kategori & kondisi termal ruangan.

## Cara Menjalankan
```bash
pip install -r requirements.txt
python app.py
```
Buka `http://127.0.0.1:5000` di browser.
